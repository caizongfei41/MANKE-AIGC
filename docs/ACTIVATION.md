# 密码激活

程序采用**本地密码激活**：首次启动进入密码页，输入正确密码后本机长期有效，无需联网、无需机器码。

## 首次激活

1. 启动 `Manke.exe`；
2. 在密码页输入：

   ```
   mankeaigc
   ```

3. 点击「激活」或回车；显示“激活成功，正在进入…”后自动进入主界面。

激活成功后会在数据目录写入标记文件：

```
<程序目录>\data\password-ok
```

## 重新激活 / 换机

- 想重新走一遍激活：关闭程序，删除 `data\password-ok`，再启动即可；
- 换电脑：把整个程序目录拷过去时，如果连同 `data\` 一起拷，则会保留激活状态；只想带作品就只备份 `data\` 里的项目/画布数据。

## 说明

- 激活状态只与本机数据目录绑定，不写注册表、不联网；
- 密码页样式与主界面一致，支持回车提交与错误提示；
- 设置页的授权状态显示为「密码激活」。

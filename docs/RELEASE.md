# 发布说明

- 产品：漫客（MANKE-AIGC 本地画布）
- 版本：**v2.10.79**（build 689，构建于 2026-11-01）
- 可执行文件：`Manke.exe`
- 默认安装目录：`{系统盘}\Manke`

程序包不在本仓库内（体积较大），发布目录中提供两种形态：

> 便携版解压即用；安装版带开始菜单/桌面快捷方式与卸载项。两者数据都保存在程序目录 `data\`。

## 目录约定

```
Manke.exe                 主程序
data\                     项目 / 画布 / 素材 / 密钥 / 激活标记
backends\                 模型后端（模型包解压到这里，或 set-models-dir.bat 指向别处）
resources\app.asar        前端与主进程资源
```

## 首次启动

1. 输入激活密码 `mankeaigc`；
2. 走一次首次运行向导（协议 → 位置 → 完成）；
3. 按需安装模型包（见 [MODELS.md](MODELS.md)）。

## 升级

- 程序升级只需替换程序文件，`data\` 与 `backends\` 不动；
- 便携版更新：保留 `data\` 与 `backends\`，替换其余文件即可。
